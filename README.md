# Política de Privacidad - FogarApp

**Última actualización:** 17 de agosto de 2026

## Información que recopilamos
FogarApp recopila información básica de tu cuenta de Google (nombre, correo electrónico y foto de perfil) únicamente para identificarte dentro de la aplicación.

## Uso de la información
La información recopilada se usa exclusivamente para:
- Identificar al usuario dentro de la app
- Gestionar pedidos de domicilios
- Mostrar el historial de pedidos

## Almacenamiento
Los datos se almacenan de forma segura en Firebase (Google Cloud) y no son compartidos con terceros.
